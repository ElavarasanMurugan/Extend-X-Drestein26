# 📜 EXTEND-X 2026 — Common Rules & Code Policy

These rules apply to **all participants** competing in **EXTEND-X 2026** at Saveetha Engineering College across both Problem Statements.

---

## 🤖 1. AI Tools Policy

Participants are **permitted** to use modern AI development tools, including but not limited to:
* **ChatGPT**, **Gemini**, **Claude**, **DeepSeek**
* **GitHub Copilot**, **Cursor**, **Supermaven**, **Windsurf**
* AI code generators, snippet generators, and documentation assistants.

---

## 🚫 2. Originality & Fair Play

1. **No Plagiarism**: Copying another team's source code, UI designs, or project logic is strictly prohibited.
2. **Fresh Development**: The specific extension solution must be built **during the official EXTEND-X event window** after the problem statements are revealed. Submitting pre-existing commercial extensions or past projects is strictly forbidden.
3. **Open-Source Attribution**: If open-source components or UI boilerplates are used, proper attribution must be maintained.

---

## 🔌 3. External APIs, Libraries & Services

1. **Permitted Resources**: Teams may integrate open-source npm packages, external REST/GraphQL APIs, machine learning models, cloud services, and third-party styling frameworks.
2. **Mandatory Disclosure**: All external APIs, major libraries, AI endpoints (e.g., OpenAI API, Gemini API, HuggingFace), and third-party services **must be explicitly listed and disclosed** during the final presentation.
3. **API Keys**: Ensure your API keys are handled securely and do not leak sensitive credentials.

---

## 🎯 4. Functional MVP & Scope Focus

1. **Browser Target**: The submission must run properly as a **Chrome Extension** (Manifest V3 recommended) in Google Chrome.
2. **Demonstrable Quality**: Teams are responsible for ensuring that their extension can be loaded into Chrome (`chrome://extensions` -> Developer Mode -> Load Unpacked) and demonstrated live to judges without breaking.
3. **Scope Control**: Build smart. Keep the scope realistic within the allotted event time. Focus on solving the core problem exceptionally well rather than attempting to build too many incomplete features.

---

## 🔒 5. Ethics & Browser Safety

1. **No Malicious Behavior**: Extensions must not harvest private user data, execute arbitrary remote malicious scripts, or perform unethical tracking.
2. **Respectful UX**: Extensions should respect website layout integrity and not crash the user's browser session.
